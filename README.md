# MASIH HACKRING | RAP فارسی
نسخه‌ی اولیه‌ی سایت مستقل رپ فارسی؛ طراحی واکنش‌گرا با جست‌وجوی کارت‌ها و پخش‌کننده‌ی HTML Audio.

## پیش‌نمایش محلی
فایل `index.html` را در مرورگر باز کنید. برای آزمایش دقیق‌تر می‌توانید یک وب‌سرور محلی اجرا کنید.

## انتشار روی GitHub Pages
1. یک مخزن جدید بسازید، مثلاً `masih-hackring-rap`.
2. تمام فایل‌های این پوشه را در ریشه‌ی مخزن قرار دهید.
3. در GitHub وارد `Settings → Pages` شوید.
4. گزینه‌ی `Deploy from a branch`، شاخه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب کنید.
5. پس از انتشار، آدرس Pages که خود GitHub نشان می‌دهد را باز کنید.

## افزودن آهنگ مجاز
1. فایل صوتی‌ای را که مالک آن هستید یا مجوز انتشارش را دارید، در `assets/audio/` قرار دهید.
2. در کارت مربوط به آهنگ در `index.html` مقدار `data-src` دکمه‌ی پخش را به مسیر فایل بدهید، مانند:
   `data-src="assets/audio/song-name.mp3"`
3. برای فعال‌کردن دانلود نیز همان مسیر را به `data-src` دکمه‌ی دانلود بدهید و ویژگی `disabled` آن را حذف کنید.
4. عنوان، نام هنرمند و `data-category` کارت را مطابق اطلاعات واقعی اصلاح کنید.

کارت‌های موجود نمونه‌اند و آهنگ واقعی ندارند. ایمیل داخل بخش همکاری نیز نمونه است و باید قبل از انتشار با نشانی واقعی جایگزین شود.

## محدودیت‌های نسخه‌ی اول
این نسخه استاتیک است؛ پنل مدیریت، ورود کاربران، آپلود مستقیم آهنگ و آمار شنونده ندارد. این قابلیت‌ها به بک‌اند و ذخیره‌سازی نیاز دارند. برای میزبانی استاتیک، GitHub Pages کافی است؛ Render هم می‌تواند سایت استاتیک را میزبانی کند.
